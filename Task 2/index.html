إبراهيم إيهاب مبروك

مشروعي: نبذة عني كمبرمج Front-End

أنا إبراهيم، مبرمج واجهات أمامية مهتم بإنشاء صفحات ويب بسيطة وجذابة وسهلة الاستخدام. أتعلم باستمرار وأطوّر مهاراتي في تصميم وبرمجة المواقع.

مهاراتي

  • HTML لبناء صفحات الويب
  • CSS لتنسيق الصفحات وتصميمها
  • JavaScript لإضافة التفاعل إلى المواقع

هواياتي

  • تعلّم تقنيات وبرامج جديدة
  • تصميم وتجربة أفكار لواجهات المواقع
  • القراءة واستكشاف مجالات جديدة
